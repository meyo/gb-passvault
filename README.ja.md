# GB パスワード帳（GB Password Keeper）

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

> 注：正式な実装サマリー（`docs/05`）は現在中国語のみです。

> ⚠️ **本プロジェクトは実機 ROM 路線（GBDK-2020 C 直接ビルド）に移行しました**：成果物は `build/passmgr.gb`（**V0.3.7.1**、
> 255 スロット + 20 文字ラベル/ユーザー名 + 6 桁 PIN + ランダムパスワード生成 + 32KB SRAM セーブ +
> ゴミ箱/自動ロック/生成設定 + **2bpp グラフィック PIN 画面** + **PMG5 デュアルヘッダ/CRC16/WAL セーブ保護**
> + **任意の 12 桁リカバリーコード**）、**353/353 自動テスト合格**；**V0.3.7.1 は実機検証待ち**。**現在のプロジェクト状況は
> [`docs/05-GBDK实机版实现总结.md`](docs/05-GBDK实机版实现总结.md) を参照してください**。
> この README と `docs/01~04`、`plugins/`、`assets/` は初期の GB Studio 方式の資料であり、設計参考のみです。
> V0.3.3 の ASCII `+--+` 分割 PIN 画面は廃止されました。V0.3.4 で `art/gb_login_filled.png` に基づき
> 2bpp グラフィック分割枠 + 立体キーキャップに作り直しました。V0.3.5 で 6 つの分割枠を 2×3 から **3×3 タイル**に拡大しました。
> V0.3.6 で 9-slice パネル/アイコン/ヘッダー・フッター、メニューとリストの選択バー、詳細フィールドカード、ゴミ箱の空状態を追加；
> PIN 画面は V0.3.5 の外観を維持しています。
> **V0.3.6.1 修正**：詳細画面を完全に閉じた枠に変更（左右の枠が欠けなくなりました）；クイックロックを
> `B+SELECT` から、入力画面以外での **B 長押し約 1.5 秒**に変更。B の短押しは従来どおり戻ります。
> **V0.3.7 セーブ信頼性**：PMG5 高領域のデュアルヘッダ A/B + レコードごとの CRC16 + 書き込み前ログ WAL；
> PMG4 セーブは電源投入時にスロットを移動せずその場で自動アップグレード；破損レコードは `SAVE DAMAGED` と表示し、残りのデータは使用可能です。
> **V0.3.7.1 忘れた PIN / 通知ラベル**：初回設定または PMG3 移行完了後に、**任意で 12 桁リカバリーコード**を生成できます；
> SRAM には 2 つの 64-bit ハッシュ（`0x5730`/`0x5750`、CRC16 + WAL）のみを保存し、**リカバリーコードの平文は保存しません**。
> PIN 画面で `SELECT`、または 3 回失敗後の `SYSTEM LOCKED` 画面で `SELECT` を押し、リカバリーコードを入力すると PIN を再設定できます。
> `SETTINGS` でリカバリーコードの作成/置換/削除が可能です。保存成功などの一時メッセージは**画面中央の長方形ラベル**に変更
> （8〜10 行目を先にクリアし、9-slice 枠 + 中央揃え文字）。
>
> **V0.3.7.1 クイックスタート**：`build/passmgr.gb` を書き込む（MBC1+RAM+BATTERY、32KB 以上の SRAM セーブ対応カートリッジが必要）。
> 初回起動時に **6 桁 PIN** を設定し、その後 12 桁リカバリーコードをスキップまたは生成できます。PIN 画面は `SECRET VAULT` タイトル +
> 6 つの拡張グラフィック分割枠 + 立体数字キーパッド（`CLR` で全消去、`B` で 1 文字削除、`START` で確定）。
> メインメニューの `ADD ACCOUNT` ではラベル（≤20）、ユーザー名（≤20、空欄可）、
> パスワード（≤36；パスワード画面で `SELECT` を押すと強力なランダムパスワードを生成、再度押すと再生成）を入力します。
> `VIEW ACCOUNTS` リスト：上下で 1 件ずつ移動（長押しで連続スクロール）、**左右で 12 件ずつページ送り**、
> **`SELECT` でラベル/ユーザー名表示を切り替え**；選択中の長いラベルは自動でマーキー表示されます。
> 詳細画面では `A` 長押しでパスワードを表示、**`SELECT+START` 同時押しで編集**、`START` 単押しで削除（**ゴミ箱へ移動**、復元可能）。
> `SETTINGS` では生成パスワード長（12/16/24/32）、記号オン/オフ、**自動ロック時間（1/2/3/5/10 分）**、
> **リカバリーコード ON/OFF（作成/置換/削除）**を設定できます；
> `RECYCLE BIN` は最近削除した 16 件を保持：`A` で復元、`SELECT` で 1 件を完全削除、`START` で全消去（いずれも確認あり）。
> **クイックロック**：メニュー/リスト/詳細/設定/ゴミ箱で **B を約 1.5 秒長押し**すると即座に PIN 画面へ戻ります；
> B の短押しは従来どおり戻ります。テキスト入力と PIN 入力画面では無効（`B=削除`との競合を避けるため）。
>
> **セーブ保護**：PMG5 のデュアルヘッダ/CRC が分離可能なレコード破損を検出すると `SAVE DAMAGED` を表示；
> `A=CONTINUE` で残りのデータを継続使用でき、メインメニューに `BAD nnn RECORDS` を表示；全体のチェックサム失敗時は
> `SAVE CORRUPT`、未知の形式は `UNSUPPORTED SAVE` を表示。いずれも**自動では消去されません**；
> `START` の後に `A` を押した場合のみ明示的に消去されます。
>
> **V0.3 からのアップグレード**：電池付きセーブをそのまま保持し、電源投入時に表示に従って旧 **4 桁 PIN** を入力し、新しい **6 桁 PIN** を設定します；
> 旧アカウントのラベルとパスワードは完全に移行され、ユーザー名は空欄になり、1 件ずつ入力できます。移行完了後にリカバリーコードを任意で生成できます。
> 移行画面に `DO NOT POWER OFF` が表示されている間は電源を切らないでください。移行後、旧 V0.3 ROM は新しいセーブを読み取れません
> （V0.3 ベースラインは `archive/v0.3/` に保存）。
> **V0.3.1–V0.3.6 からのアップグレード**：PMG4 セーブは PMG5 へその場で自動アップグレード（デュアルヘッダ/CRC/WAL）、
> スロットを移動せず、PIN の再入力も不要；アップグレード後も旧 PMG4 ROM は低領域ミラーを読み取り専用で読めますが、
> **旧版での書き込みは推奨しません**。**V0.3.7 から V0.3.7.1 へのアップグレード**：PMG5 セーブ形式は変わらないため、
> 新しい ROM を書き込むだけで、設定済みのリカバリーコードは保持されます。**アップグレード前にセーブをバックアップ（dump）してください。**

## 初回クローン / ビルド

リポジトリには展開済みの `tools/gbdk/` と `tools/emu/node_modules/` はコミットされていませんが、固定版の `tools/gbdk-macos.tar.gz` が同梱されています。初回クローン後に実行してください：

```bash
./tools/bootstrap.sh
./build.sh
node tools/emu/smoke.js
```

`bootstrap.sh` はツールチェーンがない場合に GBDK を展開し `serverboy` をインストールします。その後 `build.sh` が `build/passmgr.gb` を生成し、スモークテストの結果は `test_out/smoke.log` に書き出されます。

> 以下は初期の **GB Studio 4.x** プロトタイプ方式の資料です（歴史的アーカイブであり、現在の ROM 実装ではありません）：
>
> **GB Studio 4.x** で制作し、**Game Boy / GBC 実機またはエミュレーター**で動作する
> レトロな「オフラインパスワード帳」プロジェクト枠 + コアロジックスクリプトです。

- 🕹 メインメニュー：アカウント表示 / スロット編集 / PIN 変更 / ロック
- 🗄 データモデル：8 アカウントスロット × 12 文字ラベル + 12 文字パスワード（文字コード配列）
- 💾 永続化：`Game Data Save/Load`（SRAM + 電池バックアップ）、電源を切っても消失しない
- ⌨️ 仮想キーボード：48 キーグリッド + 十字キーカーソル + A キーで確定（ほかに 4 桁数字 PIN キーパッド）
- 🔒 ロック解除 PIN：4 桁数字、+7 で難読化して保存、3 回間違えるとイースターエッグ
- 🧩 任意プラグイン：「配列の読み書き / XOR 難読化」を 3 つのカスタムイベントに変換（GBVM 間接アドレッシング）

> ⚠️ 正直な注意：これはおもちゃレベルの「儀式感」パスワード帳であり、SRAM の内容は読み取れます。
> 実際の重要なパスワードは保存しないでください（詳細は `docs/04` 第 8 節）。

## クイックスタート

1. GB Studio 4.3+ で新規プロジェクト → カートリッジタイプで **BATTERY 付き**を選択（Project Settings）；
2. `docs/03` を開き、番号順に変数をリネーム（連続区間の番号を飛ばさない）；
3. （任意）`plugins/password-manager` をプロジェクト直下の `plugins/` にコピーし、
   エディターを再起動 → イベント一覧に **Password Manager** グループが表示される；
4. `docs/01` に従って 6 つのシーンと静的背景を作成し、`docs/02` に従ってイベントを貼る；
5. `docs/02` 第 10 節の「通し自己テストチェックリスト」で検証する。

## 推奨読書順

- まず構造を理解したい：`01` → `03` → `02`
- すぐに作り始めたい：`03`（変数作成）→ `02`（ロジック貼り付け）→ `04`（問題発生時に diff）
- GBVM / プラグインを学びたい：`plugins/password-manager/README.md` + `04` 第 7 節

## バージョンについて

- 対象：GB Studio **4.3.x（安定版）**；4.2 以前では「純ビジュアル代替案」（`02` 第 8 節）が使用可能；
- 4.4 開発版で**ネイティブ配列変数**が導入された後は、プラグインの使い方をそのまま置き換え可能で、データモデルの変更は不要です。

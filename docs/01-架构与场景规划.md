# 01 · 项目架构与场景规划

> 目标平台：Game Boy / Game Boy Color（DMG 兼容）
> 开发工具：GB Studio 4.x（当前稳定版 4.3.x；提示见 `docs/04`）
> 项目类型：非游戏工具（离线密码本），最大 8 个账号槽位

---

## 1. 总体思路

GB Studio 本质是「事件驱动的场景机」。把密码本拆成若干**全屏 UI 场景**，
用 `Change Scene` 串联；数据全部放在**全局变量**里，用
`Game Data Save / Load`（SRAM + 电池）做持久化。

```text
                    ┌────────────────────────────┐
                    │  SCN_Boot  启动/锁屏         │
                    │  On Init:                   │
                    │   读档 / 首次初始化           │
                    │   → 跳转 PIN 输入            │
                    └──────────┬─────────────────┘
                               │ PIN 正确
                    ┌──────────▼─────────────────┐
                    │  SCN_Menu  主菜单            │
                    │  [1] 查看账号  [2] 新建/编辑  │
                    │  [3] 修改 PIN  [4] 锁定退出   │
                    └─┬────────┬────────┬────────┘
        ┌─────────────┘        │        └──────────────┐
        │                      │                       │
┌───────▼────────┐   ┌─────────▼──────────┐   ┌────────▼────────┐
│ SCN_List 列表   │   │ SCN_Edit 编辑/键盘   │   │ SCN_Pin 数字键盘 │
│ 选槽位 → 详情    │   │ 虚拟键盘输入标签/密码 │   │ 解锁 / 设新 PIN  │
└───────┬────────┘   └─────────┬──────────┘   └────────┬────────┘
        │                      │ Game Data Save        │
┌───────▼────────┐             │                       │
│ SCN_Detail 详情 │             └──────────► 返回 SCN_List
│ 隐藏/显示密码    │
└────────────────┘
```

> 场景跳转用 `Scene → Change Scene` 事件；进入任何场景后建议先执行
> 运行时变量复位（`$LEN`、`$SEL_*` 等），保证行为可预期。

## 2. 场景清单

| # | 场景名 | 作用 | 关键内容 |
|---|--------|------|----------|
| 1 | `SCN_Boot` | 启动、读档、初始化 | On Init 脚本、锁屏画面、走向 PIN 输入 |
| 2 | `SCN_Pin` | 4 位数字 PIN 键盘 | 数字小键盘背景、光标、校验/设置逻辑 |
| 3 | `SCN_Menu` | 主菜单 | `Display Menu` 四个选项 |
| 4 | `SCN_List` | 账号槽位列表 | `Display Menu` 列出 8 个槽位 |
| 5 | `SCN_Detail` | 账号详情 | 标签 + 密码显示、A 键显示/隐藏、B 返回、进入编辑 |
| 6 | `SCN_Edit` | 录入/编辑界面 | 48 键虚拟键盘、光标、保存 |

建议再建 2 个**自定义脚本（Custom Scripts）**做公共子程序：

| 自定义脚本 | 作用 |
|------------|------|
| `KEYPAD_MAIN` | 编辑界面的 48 键键盘主循环（移动光标、提交字符、退格、切换字段） |
| `ARRAY_INIT` | 首次开机时把标签/密码数据库全部填充空格（0x20 = 32） |

## 3. 截图版"背景"里要画什么

GB Studio 的场景背景就是 UI。用背景编辑器直接画（文字用项目字体打上去即可）：

**SCN_Edit 背景示例（20×18 瓦片）：**

```text
行0:  LABEL  = ______________________________      ← 代码用 Draw Text 覆盖
行1:  SECRET = ______________________________      ← 代码用 Draw Text 覆盖
行2:  ────────────────────────────────────────      ← 分割线（画死）
行3:    ▼ (列指示，代码画)
行4:  ▶  0  1  2  3  4  5  6  7                 ← 静态键面（画死）
行5:  ▶  A  B  C  D  E  F  G  H
行6:  ▶  I  J  K  L  M  N  O  P
行7:  ▶  Q  R  S  T  U  V  W  X
行8:  ▶  Y  Z  !  ?  @  #  $  %
行9:  ▶  _  -  .  /  DEL CLR SPC OK
```

- 键面行列（行4–行9 的 8×6 网格）是**静态背景**；
- `▶`/`▼` 两个指示箭头和输入框里的字符、光标都由脚本用 `Draw Text` 动态绘制；
- 每格 1 个瓦片，键盘共 48 键：编号 = 行(0–5)×8 + 列(0–7)。

**SCN_Pin 背景**：3 列 × 4 行的数字键盘（1–9、0 居中），格式同上面板（编号 = 行×3 + 列）。

## 4. 输入设备与玩家角色

这些「工具场景」里不需要走路与碰撞：

- 场景里保留玩家出生点即可，但建议在场景 On Init 里：
  - `Actor → Hide Actor`（隐藏玩家精灵）或 `Set Player Sprite Sheet = None`；
  - 场景尺寸就设为 20×18（一屏，不滚动，摄像机锁定）；
- **脚本运行时 GB Studio 会自动暂停玩家的移动输入**，所以键盘循环脚本不会被
  "主角乱走"干扰；脚本按 B/A/Start 处理自己的逻辑即可。

## 5. 资源与设置清单

| 项目 | 设置 |
|------|------|
| 卡带类型 | **ROM Only + RAM + BATTERY**（存档必须带电池） |
| 显示模式 | 建议 GBC 兼容 + DMG 调色板（4 色灰度复古感）；GBC 可用 8 色调色板做"高亮" |
| 色彩 | 背景 4 色（GB 限制），前景高亮用 `\007\002` 反白文本实现 |
| 字体 | 默认字体即可；**不支持中文**（见 docs/04 第 6 节） |
| 音效 | 可加 "Beep" 打字音效（`Set Text Sound Effect`）；本项目默认无 BGM |
| 调试 | 打开 GB Studio Debugger 的 Variables 面板观察变量；模拟器需开启 SRAM/电池存档 |

---

## 6. 建议的开发顺序

1. 建变量表（`docs/03`），全部按顺序重命名；
2. 建 6 个场景与静态背景；
3. 安装（可选）`plugins/password-manager`；
4. 按 `docs/02` 逐场景贴事件；
5. 用调试器跑通「初始化 → 设 PIN → 新建账号 → 保存 → 重启读档 → 解锁 → 查看」；
6. 最后再加音效、开机标题、彩蛋（如 PIN 输错 3 次的"锁定"动画）。
